DSH 会话 HUD —— 安装说明
========================================================================

这是什么
--------
一个把 DeepSeek Harness 正在运行的会话「现在在干什么、有没有在等你批准」
钉在屏幕角落的悬浮窗。

装好之后你会得到三样东西：
  * 随 DSH 一起自动打开的悬浮窗（可拖动、缩放、置顶、跟随系统明暗主题）；
  * DSH 侧边栏底部、设置按钮旁边的「打开 HUD」按钮；
  * 会话里的 /hud 命令。
后两者用来在窗口被关掉之后把它叫回来（不用重启 DSH）。


环境要求
--------
Windows 10 1809（build 17763）或更高。

不需要安装 .NET，也不需要 Windows App Runtime —— 这个包里已经带全了运行时。
总的解压后体积约 170 MB，请留出空间。


最快的装法（推荐）
------------------
1. 把整个文件夹解压到一个固定的位置。
   （不要留在临时目录或压缩包里运行 —— 装好之后这个文件夹要一直留着。）

2. 打开这个文件夹，在空白处按住 Shift + 右键 → 「在此处打开 PowerShell 窗口」
   （或「在终端中打开」）。

3. 执行：

       .\install.ps1

   如果提示「禁止运行脚本」，先执行一次这个再重试：

       Set-ExecutionPolicy -Scope Process Bypass

4. 看到「装好了」之后，**重启 DSH**。

脚本会做这些事，都会打印出来：
   * 确认 dist\DshSessionHud.exe 在；
   * 往 DSH profile 里声明这个插件（依赖 + bundle 列表）；
   * 在 profile 目录跑一次依赖安装（用 DSH 自带的 node/pnpm）；
   * 改之前会把 profile 的 package.json 备份成 package.json.bak。

想指定装进别的 profile：

    .\install.ps1 -Profile <名字>


手动装法（脚本跑不通时）
------------------------
方法 A：用 DSH 的插件管理器
  1. 打开插件管理器，添加一个包，填这个文件夹的绝对路径（前面加 link:），例如：

         link:C:\你解压到的地方\dsh-session-hud-1.1.0

  2. 重启 DSH。

方法 B：直接编辑 profile 的 package.json
  文件在 %USERPROFILE%\.dsh\profiles\<profile>\package.json。
  dependencies 里加一行：

      "dsh-session-hud": "link:C:/你解压到的地方/dsh-session-hud-1.1.0"

  dsh.profile.bundles 里加上 "dsh-session-hud"，然后在该目录跑一次 pnpm install。


装完之后怎么用
--------------
* 窗口：拖标题栏移动，拖边缘缩放。标题栏四个按钮分别是
  置顶 / 精简 / 视图模式（列表↔格子）/ 设置。
* 设置面板能调：最多显示几个会话、空闲超过多少分钟隐藏、明暗主题。
  等待批准和正在运行的会话永远不会被隐藏。
* 窗口的位置、大小、开关、设置都会记住，下次打开保持原样。


卸载
----
在插件管理器里移除 dsh-session-hud，然后重启 DSH。

想彻底清干净，再删掉这两个文件：

    %USERPROFILE%\.dsh\session-hud\state.json
    %LOCALAPPDATA%\DshSessionHud\window.json


出问题了
--------
先看 README.md 的「排查」一节。最常遇到的两个：

* 装完什么都没出现
  → 大概率没重启 DSH。换过依赖形式（比如以前装过别的版本）之后必须重启。

* 窗口是空白的 / 一直显示「等待心跳…」
  → 状态文件读取失败。状态栏会写明原因；也可以直接打开
     %USERPROFILE%\.dsh\session-hud\state.json 看有没有异常的字段类型。

* 这个文件夹被移动或删除了
  → 插件是按路径链接进来的，挪走就失效了。挪回去，或者用插件管理器重新装一次。
